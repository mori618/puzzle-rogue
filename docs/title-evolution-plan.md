# 二つ名：セットシナジー廃止と進化二つ名の追加（グループ 11・案）

**実装済み**（案のとおり。E50 幾何の を含む）。決めてほしいこと 1〜3 は案のまま採用した（E27・E28 は「A枠の属性に合わせる」1 件ずつ、S06 は方形の＋方陣師 に付け替え、廃止 9 件）。

数値はグループ 7〜10 を入れた後のもの（S13・S16 はグループ 7・9 で変更済み、S20・S39 はグループ 7 で無効化済み）を元にしています。

## 方針

- **強さの決め方**：進化二つ名は元の二つ名と同じ枠を使い、元の二つ名の代わりに装備する。今のセットは「元の 2 つ＋セット効果」だったので、
  **進化 ＝ 元の二つ名の効果 ＋ セット効果の 6〜8 割**を目安にした（もう片方の枠には別の二つ名を入れられるため、セット効果を丸ごと移すと強くなりすぎる）。
- **解放条件の種類**
  - a：「『A』を装備して〜する」（今の進化と同じ）
  - b：「『A』と『B』を装備して〜する」（A枠＋B枠）
  - c：「『A』と『A'』を解放した状態で〜する」（A枠どうし・B枠どうしは必ずこれ）
- グループ 7〜10 の方針を守る：ゲーム開始時の効果なし、エンチャント・虹ドロップは使わない、ボムは 1 手 3 個まで、表記は「アクティブトークン」「アクティブスキル」。

### 強さの確認メモ

- 元の二つ名より強い：E29（神速の +1 秒・コンボ +5）→ 基礎 ×1.75、E43（孤高の 倍率 +2.0）→ +2.0 と最終 ×1.5 など、すべて元の効果を含むか上回る。
- 同じ元から 2 つ進化するもの：神速の（E01・E29）、孤高の（E43 は A枠、E44 は B枠）。E01 と E29 は倍率加算と基礎倍率で役割を分けた。
- 最終倍率が大きいもの（E42 ×2.5、E44 最大 ×2.7）は解放条件を最も重くした（サイクル 25、トークン 0 でサイクル 5）。

## 3. 実装の方針

### データの形

```js
{
  id: 'E29', name: '電撃の', category: 'A枠上位',
  slot: 'prefix',                       // 装備する枠を明示（requiredTitleId の頭文字では決めない）
  requiredTitleIds: ['A01', 'B08'],     // 元の二つ名。配列の中の配列は「どれか 1 つ」
                                        //   例: ['B01', ['A04','A05','A06','A07','A08','A09']]
  requiredMin: undefined,               // c で「N 個以上」のとき（E47: 詠唱 6 つのうち 3 つ）
  requireMode: 'equipped',              // 'equipped' | 'unlocked'
  trigger: { event: 'clear', when: { time_left_ge: 3000 } },
  challengeDesc: '「神速の」と「無双」を装備して、操作時間を3秒以上残してサイクルクリア',
  desc: '…', effects: [ … ],
}
```

- 解放判定（titleManager の recordTitleTrigger）：
  - `requireMode: 'equipped'` … requiredTitleIds のすべて（どれか 1 つのグループは 1 つ以上）を装備中。元の二つ名の進化版を装備していても装備中として扱う（今の isTitleEquipped と同じ）。
  - `requireMode: 'unlocked'` … requiredTitleIds がすべて解放済み（requiredMin があればその数以上）。
- E27・E28 の「A枠に装備した属性」は、効果に `attribute: '$prefix'` のような指定を入れ、装備中の A枠（とその進化）の属性に置き換えて計算する。属性の A枠は `attribute` を持たせる（A04: 'fire' など）。
- 「1 回のショップで〜」（E30・E35・E37）や「1 手で特殊消し 3 種類」（E50）など、判定に足りない値は、手番・ショップの進捗に 1 回ごとの値として足す。

### 今の進化（E01〜E26）の移し方

- `requiredTitleId: 'A01'` → `requiredTitleIds: ['A01']`、`slot` は今の計算結果（頭文字）を書き写す。
- `trigger.requireEquipped: true` → `requireMode: 'equipped'`。E08 パズルマスター（進捗で解放、装備不要）は `requireMode: 'unlocked'`。
- id は変えないので、解放済みのセーブデータはそのまま使える。

### セーブデータ

- セットシナジーは解放の記録を持っていない（装備の組み合わせで発動するだけ）ので、TITLE_SET_BONUSES を消してもセーブデータは壊れない。
- 二つ名の解放数（B50 伝説 の条件）は進化が増える分だけ増えやすくなる。セットは数えていなかったので、差は進化の増加分だけ。

### 図鑑

- 「隠しセット効果」の欄を消す。
- 進化二つ名のカードに、元の二つ名（複数）と「装備して」「解放した状態で」の区別を表示する。元の二つ名が未解放のうちは今と同じく名前を伏せる。
- 名前の表示：今はセットがあると【〇〇】の名前に置き換わっていた。廃止後は A枠と B枠の名前をつなげるだけになる。

### 決めてほしいこと

1. **E27・E28 のまとめ方**：属性ごとに 6 件ずつ作る（合計 12 件）か、案のように「A枠の属性に合わせる」1 件ずつにするか。案は 1 件ずつ（新しい効果の指定 `attribute: '$prefix'` が必要）。
2. **S06 の付け替え**：絶対障壁の方陣（厄災の＋方陣師）を、案では方形の＋方陣師 に付け替えた。厄災の（呪い）側に残したい場合は別の効果を考える。
3. **廃止 9 件**：既存の進化で代わりになると判断したもの。残したいものがあれば教えてください。
4. **E50 幾何の**（セットの移し替えではない新規）を入れるかどうか。
