# Claude 依頼用プロンプト集（テストプレイログ分析 2026-11-02）

2026-11-01〜02 のテストプレイログ 9 ラン（重複除く）の分析結果と、開発者の追加案をまとめたもの。
似た内容ごとにグループ化してあるので、**1 グループ = 1 回の依頼**として、各「プロンプト」欄をそのまま Claude に貼り付けて使う。

## 分析の要点（共通の背景）

- 9 ラン中 8 ランがサイクル 6 で終了（目標 368 に対し最高 166 = 45%）。サイクル 1〜5（目標 8〜56）はほぼ毎回 1〜2 手でクリアし、残りはスキップしていた。
- 二つ名がサイクル 1〜5 のコンボを 2〜4 倍に押し上げており、トークンを育てなくても序盤を抜けられてしまう。一方、固定値の加算はサイクル 6 以降で伸びない。
- 死亡時にスターが平均 36（12〜84）余り、トークン枠の拡張は全ランで 0 回だった。
- 効いていたトークンは倍率系（月の真髄・常闇の共鳴・業水の律動・各色の連舞・重力逆転）。条件の重い発動型トークンは、サイクル 6 までにほぼ発動しなかった。

## グループ 6：ドロップ変換の演出を追加する

**背景**（テストプレイのメモより）：ドロップが別の種類に変わる効果に演出がなく、急に変わったように見えて驚く。特に、ターン終了後に自動で変換される処理（`turn_end_convert` など）は、気づいたら盤面が変わっている感じがある。

**プロンプト**

```
ドロップが別の種類に変換されるときの演出を追加したいです。
今は一瞬で切り替わるため、特にターン終了後の自動変換が
「いきなり変わった」ように見えて驚きます。

対象：
- ターン終了時の自動変換（src/hooks/useGameState.js の turn_end_convert 処理、
  4128行付近と、アクティブバフによる変換）
- スキルによる変換（src/engine/PuzzleEngine.js の convertColor / convertMultiColor /
  convertPairColors / convertAreaToColor / convertStarTargeted /
  convertBombTargeted / convertRepeatTargeted / convertRowNeighbors など）
- 侵食系（erosion_*）など、ターン経過で盤面が書き換わる効果全般

演出の要件：
- 変換されるマスを短く光らせてから（0.15秒程度）、新しいドロップへ

  （合計0.5秒以内）。

  トークンアイコンを光らせるか通知を出してください。
- 設定の速度倍率（speedMultiplier）に合わせて演出時間を短縮してください。
- 演出中は盤面操作を受け付けないようにし、演出終了後に操作できるようにしてください。
- 既存の生成演出（プラス・リピートドロップなどの生成時）があれば、
  見た目を揃えてください。

実機（スマホ幅）で違和感がないか、可能なら画面確認してください。
npm test と npm run build が通ることを確認してください。
```
