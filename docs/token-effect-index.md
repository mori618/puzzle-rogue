# トークン効果の指標表

`node balance-sim/sim/effect-index.mjs` で作り直せます（数値は `src/constants/tokens.js` から読み、分類は `useGameState.js` の handleTurnEnd の実装に合わせています）。

## 計算式

```
最終コンボ = (盤面のコンボ + ①コンボ加算) × (1 + ②加算倍率の合計) × ③乗算倍率の積
```

- ① は「+N コンボ」、② は「コンボ倍率にプラス X」、③ は「コンボ倍率が ×X」。
- ② は同じ段どうしで足し算なので、持てば持つほど1個あたりの伸びが小さくなる。③ は掛け算なので、持つほど伸びが大きくなる。
- 値は「発動したときに実際に入る値」。説明文の「プラス{values}」は、実装では values−1 を足しているものが多い（例: 炎の力 values=[2,3,4] → 実際は +1/+2/+3）。
- 色違いなど同じ効果のトークンは1行にまとめ、統計も1件として数えています（「ほかN種」）。
- 「実測」は balance-sim の単体テスト（トークン1個だけで15手番、ボットのプレイ）での平均コンボの増加率（Lv1 / 最大Lv）。条件をボットが狙わないトークンは低く出ます。③の実測は、Lv3を旧Lv2の値に下げる前の測定です。
- エンチャントは廃止済みなので対象外。

### 段ごとの効き方の目安

盤面8コンボ、②の合計 +3（倍率4）、③なし のときに、各段の「中央値の1個」を足すと:

- ① コンボ加算: 中央値 +15 / +40 / +100 → 32 が 92 / 192 / 432（Lv1 / Lv2 / Lv3）
- ② 加算倍率: 中央値 +1 / +2 / +4 → 32 が 40 / 48 / 64（Lv1 / Lv2 / Lv3）
- ③ 乗算倍率: 中央値 ×2 / ×2.3 / ×3 → 32 が 64 / 73 / 96（Lv1 / Lv2 / Lv3）

## 気になった点（数値の偏り）

- 篝火などの「12個以上」系（+2/+3/+4）が、条件の軽い「6個以上」系（+2/+3/+6）より Lv3 で弱く、価格は高い（31 vs 24）。
- リトルワールド Lv1 は ② が −0.2 で、持つと倍率が下がる。
- 癒の器（chalice_of_life）は上限（maxMultipliers）が無く、ハートを消すほど ×値^n で青天井。
- 同じパッシブを2回発動させる効果（コピー鏡・合わせ鏡・先導・殿の構え）は、③に使うと ×X が ×X² になる。②に使うと +X が +2X になるだけなので、③との相性が段違い。
